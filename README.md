# Movie Library

This application allows users to keep track of the movies they watch in a digital library. Lists can be organized by watch status and genre. 

## How to Use

Find the application [here](http://softala.haaga-helia.fi:7077/)

## Future Development

This application will be updated with more features including
* account deletion
* password recovery
* movie ratings and sorting by rating
* search functions
* watch history
* better UI and UI settings
* scaling for mobile
